# TrainXShiv Website (React + Vite)

## Run karne ke steps
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build -> dist/
```
Node 18+ chahiye.

## Apna content kahan badalna hai
| Kya | Kahan |
|---|---|
| Phone / email / Instagram | `src/data.js` -> `BRAND` |
| Programs, Prices, Plans, Diet plans, FAQ, Blog | `src/data.js` |
| Before/After photos | `public/images/transformations/1-before.jpg`, `1-after.jpg` ... (list `TRANSFORMS` me) |
| Video reviews | mp4 -> `public/videos/review1.mp4` + poster -> `public/images/reviews/r1.jpg`. YouTube chahiye to `youtube: 'VIDEO_ID'` likho |
| Hero photo (Shivam) | `public/images/hero.png` (transparent PNG best) |
| Trainer photos | `public/images/trainers/shivam.jpg, rohit.jpg, priya.jpg, aman.jpg, neha.jpg` |
| Program photos | `public/images/fat-loss.jpg, weight-gain.jpg, muscle.jpg, toning.jpg, personal.jpg, online.jpg, diet.jpg` |
| Instagram tiles | `public/images/insta-1.jpg` ... `insta-7.jpg` |
| Our story video | `public/videos/our-story.mp4` |

Jab tak photo na ho, site me premium blue placeholder dikhta hai (kuch toota hua nahi dikhega).
